# M4: researchers and evidence

The planner's financials, company, news and industry queries run concurrently. SEC companyfacts supplies exact-duration, filed-by-as-of contexts; requested-period filing metadata fills missing current filings before comparative inputs. Earnings release exhibit names come from accession directories. Company research maps a verified company root, then extracts selected earnings/results pages. No model invents a SEC accession or URL.

Tavily results must pass a score threshold, company matching and publication-date checks. SEC archive CIKs must match the resolved registrant. Primary status requires SEC or a matching company hostname; an investor prefix does not confer trust. Canonical URLs merge into one source. Basic extraction precedes advanced extraction of failed URLs only. Query-focused excerpts are recorded as page evidence; this label does not imply an entire filing was downloaded.

A small Qwen model creates bounded notes and literal facts. Numeric facts require a displayed value, unit, period and as-of date. Code rejects quotes absent from the source and scale conversions. These checks establish provenance, not semantic correctness: the writer/verifier milestone must still check metric, unit and period alignment. Search silence does not prove non-disclosure.

Concurrent requests reserve their maximum cost before dispatch, deduplicate identical calls, then reconcile the server's usage receipt. Interrupted runs resume from public responses; replay fails closed if any record is missing and uses saved notes without model calls. SEC responses, Tavily responses, notes and evidence remain in ignored local run directories. Tracing records SDK operations and model tokens without HTTP headers.

The eight-pair topic experiment favored general search (37/64 relevant results versus 15/62 for finance; 25/64 primary versus 0/62). All rankings differed. General remains the default; this small sample does not justify a universal topic claim. See `results/topic_comparison_m4.md`.

The full 30-question retrieval scorecard is in `results/researchers_m4_final.md`. It isolates retrieval with previously saved M3 plans. The judge sees equal 1,200-character source windows and no reference answers. This is a precision measure, not proof that every necessary answer input was retrieved. The recorded baseline is older, so search-index drift remains a confound; its primary classification is also more permissive than the new hostname checks.

Acceptance: relevant share 44.6% versus 24.6%; primary share 68.2% versus 11.4%; 530 facts with complete numeric metadata; mean/max credits 3.73/8.00; 30/30 exact network-blocked replays; 95 offline tests passed. The first pilot missed retrieval acceptance (31.6% versus 33.3%) before the generic filing-coverage and quantity fixes; both pilot scorecards are retained. No named-company answer exception was introduced.
